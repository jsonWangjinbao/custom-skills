# 出图自检 Checklist

## A. 硬规则：任何一项失败都不得交付
- [ ] 最终文件宽度精确为 552 px。
- [ ] 最终文件高度精确为 326 px。
- [ ] Logo 使用官方资产，不是 AI 重绘版本。
- [ ] 浅色版使用常规蓝色 Logo；深色版使用反白 Logo。
- [ ] Logo 左边距为 30 px。
- [ ] Logo 上边距为 30 px。
- [ ] Logo 显示宽度为 98 px。
- [ ] Logo 保持原比例，高度约 20 px，无拉伸变形。
- [ ] Logo 无投影、描边、发光、旋转、换色。
- [ ] 构图为固定左文右图。
- [ ] 主视觉位于右侧，未侵占左侧主标题核心阅读区。
- [ ] 已运行 `scripts/compose_banner.py`，且 `view_image` 中最终图可清晰看到 Logo。

## B. 信息检查
- [ ] 主标题与用户业务主题一致。
- [ ] 副标题/说明文字没有被擅自改写业务含义。
- [ ] 未编造日期、部门、数据或业务信息。
- [ ] 左侧文案清晰可读，背景干净。
- [ ] 主标题为抖音美好体或阿里妈妈数黑风格，标准字号 48 px。
- [ ] 副标题默认存在并使用阿里巴巴普惠体风格，标准字号 14 px。
- [ ] 封网通知副标题逐字为“安全防护 · 稳定服务 · 降低风险”。

## C. 品牌风格检查
- [ ] 使用统一企业蓝色体系。
- [ ] 浅色/深色模式符合业务场景或用户指定。
- [ ] 浅色版第一行标题为 `#1677FF`、第二行为 `#1F2329`。
- [ ] 深色版两行标题均为 `#FFFFFF`。
- [ ] 材质、光影、空间感与系列案例一致。
- [ ] 右侧主体物与业务语义直接相关。
- [ ] 没有卡通、游戏、电商促销、强赛博朋克感。
- [ ] 没有无意义复杂粒子或高饱和霓虹堆砌。

## D. AI 生图专项检查
- [ ] 底图中没有伪 Logo、错误品牌字样或乱码。
- [ ] 官方 Logo 区域没有被高亮光效或复杂元素干扰。
- [ ] 主体物没有生成到左侧文字区域。
- [ ] 不同主题内容有变化，但整体仍像同一品牌系列。
- [ ] 没有把生图工具返回的无 Logo 中间图作为最终交付。
