# AI 生图提示词模板

> 本文件用于 Skill 内部组织提示词，不要求业务用户填写。

## 1. 通用底图/主视觉模板

生成一张企业数字化品牌轮播图视觉，最终成图必须为 552×326 px 横向画布。

业务主题：{主题}
视觉隐喻：{1-3个核心视觉隐喻}
模式：{浅色/深色}

硬性构图：
- 固定左文右图。
- 左侧为文案信息区，必须保持干净、低干扰、高可读。
- 右侧为核心主体物区，根据业务主题生成精致的数字科技主视觉。
- 左上角预留官方 Logo 固定区域：距离左侧 30 px、顶部 30 px；Logo 将后期叠加，底图中不要生成任何 Logo、品牌字样、伪文字或相似标志。
- 不得改成居中、上下、右文左图或满版主视觉构图。

固定文字：
- 主标题字体为抖音美好体或阿里妈妈数黑的粗体视觉，标准字号 48 px。
- 副标题字体为阿里巴巴普惠体，标准字号 14 px；默认保留。
- 浅色版第一行标题 `#1677FF`、第二行 `#1F2329`。
- 深色版两行标题均为 `#FFFFFF`。
- 封网通知默认副标题必须逐字使用：`安全防护 · 稳定服务 · 降低风险`。

视觉语言：
- 企业级数字化科技风。
- 品牌蓝色体系。
- 简洁、专业、通透、精致、未来感。
- 统一的 3D/半透明玻璃材质、柔和体积光、数据流或科技结构。
- 主体物清晰集中，避免杂乱。

禁止：
- 伪 Logo、乱码品牌字样。
- 写实人物、卡通、游戏、电商促销、强赛博朋克。
- 高饱和霓虹、无意义粒子堆砌、复杂装饰。
- 主体物侵占左侧标题区。

## 2. 浅色模式补充
- 背景以白、极浅蓝、柔和蓝色渐变为主。
- 允许少量蓝紫/青色高光。
- 光效轻盈，留白充分。
- 主体物保持通透、精致，不要灰脏。

## 3. 深色模式补充
- 背景以深蓝为主，允许蓝紫/青蓝科技光效。
- 保持企业级克制感，不做黑客/游戏视觉。
- 左侧文字区仍需清晰，避免强光穿过文案。

## 4. 最终合成要求
生图完成后：
1. 生图结果不得包含 AI 生成的 Logo，只能预留左上区域。
2. 使用 `scripts/compose_banner.py` 将图片适配为精确 552×326 px，并按模式叠加官方 Logo。
3. 使用 `view_image` 预览合成后的最终文件，确认 Logo 清晰可见、文字配色正确、副标题存在。
4. 只交付最终合成文件，不交付无 Logo 的中间图。
5. 执行 checklist 后输出。
