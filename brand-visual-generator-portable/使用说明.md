# 万辰集团品牌视觉生成 Skill｜使用说明

## 这是什么

这是一个用于生成万辰集团数字化中心轮播图、封面图和通知图的便携包。它把品牌规则、官方 Logo、深浅色参考图、提示词模板和最终 Logo 合成脚本放在一起。

包内提供两种使用方式：

1. **原生 Skill 模式**：适用于能读取 `SKILL.md` 和文件夹资源的 AI/Agent。
2. **通用 AI 模式**：适用于不能安装 Skill、但能上传文件或设置系统提示词的 AI。

## 包内结构

```text
brand-visual-generator-portable/
```

## 固定品牌规则

- 最终画布必须为 `552 × 326 px`。
- 固定左文右图版式。
- Logo 固定在左上角：左边距 `30 px`、上边距 `30 px`、显示宽度 `98 px`。
- 浅色版使用蓝色常规 Logo；深色版使用白色反白 Logo。
- 主标题通常分两行，标准字号 `48 px`，优先使用抖音美好体或阿里妈妈数黑的粗体视觉。
- 浅色版第一行标题为品牌蓝 `#1677FF`，第二行为近黑 `#1F2329`。
- 深色版两行标题全部为白色 `#FFFFFF`。
- 默认保留副标题：标准字号 `14 px`，字体为阿里巴巴普惠体。
- “封网通知”的固定副标题为：`安全防护 · 稳定服务 · 降低风险`。
- AI 不得重绘、仿制或改写 Logo。Logo 必须使用包内官方文件后期叠加。

## 方式一：支持 Skill 的 AI

1. 解压 ZIP。
2. 将整个 `brand-visual-generator` 文件夹导入或放入该 AI 的 Skills/Agents 目录。
3. 确保 AI 能读取 `SKILL.md`、`references/`、`assets/` 和 `scripts/`。
4. 在对话中直接发出需求，例如：

   ```text
   使用 brand-visual-generator，生成一张深色的数字化中心封网通知。
   ```

5. 如果平台支持代码执行，让它在交付前运行 `scripts/compose_banner.py`，并预览最终合成图。

不同平台的 Skill 安装目录和触发语法不同；如果平台没有原生 Skill 功能，请使用下面的通用 AI 模式。

## 方式二：任意通用 AI

1. 打开 `通用AI系统提示词.md`，复制“可直接粘贴的系统提示词”到目标 AI 的系统指令、项目指令或自定义指令中。
2. 上传以下文件：

   - `brand-visual-generator/assets/wanchen-logo-regular.png`
   - `brand-visual-generator/assets/wanchen-logo-reverse.png`
   - `brand-visual-generator/assets/layout-light-reference.png`
   - `brand-visual-generator/assets/layout-dark-reference.png`

3. 提交业务需求，例如：

   ```text
   生成浅色版“数字化中心 数据库迁移”，保留副标题，右侧主视觉使用数据库与数据流。
   ```

4. 让 AI 先生成**不含 Logo 的中间图**，并在左上角预留干净区域。
5. 使用下面的脚本完成精确尺寸与官方 Logo 合成。

## 精确 Logo 合成

### 环境准备

需要 Python 3.9 或更高版本：

```bash
python -m pip install -r requirements.txt
```

### 浅色版

```bash
python brand-visual-generator/scripts/compose_banner.py input.png output.png --mode light
```

### 深色版

```bash
python brand-visual-generator/scripts/compose_banner.py input.png output.png --mode dark
```

脚本会自动：

- 将输入图裁切/缩放到精确的 `552 × 326 px`；
- 选择正确的官方 Logo；
- 将 Logo 放到 `(30, 30)`；
- 将 Logo 等比缩放到 `98 px` 宽；
- 输出最终 PNG。

输入和输出必须使用不同文件名。

## 无法运行 Python 时

可以在支持图层的设计软件中手动合成：

1. 新建 `552 × 326 px` 画布。
2. 导入 AI 生成的无 Logo 中间图并铺满画布。
3. 浅色版导入 `wanchen-logo-regular.png`；深色版导入 `wanchen-logo-reverse.png`。
4. 锁定比例，将 Logo 宽度设为 `98 px`。
5. 将 Logo 左上角坐标设为 `X=30 px, Y=30 px`。
6. 导出 PNG，并检查 Logo 未被遮挡、拉伸或变色。

## 最终验收清单

- [ ] 图片尺寸正好是 `552 × 326 px`。
- [ ] 左上角能清晰看到官方 Logo。
- [ ] Logo 坐标为 `(30, 30)`，宽度为 `98 px`。
- [ ] 浅色版使用常规蓝色 Logo；深色版使用反白 Logo。
- [ ] 主标题位于左侧，主视觉位于右侧。
- [ ] 浅色版标题第一行蓝、第二行黑。
- [ ] 深色版两行标题全白。
- [ ] 主标题为抖音美好体/阿里妈妈数黑的粗体视觉。
- [ ] 副标题默认存在；封网通知使用固定副标题。
- [ ] 没有伪 Logo、乱码品牌文字或生成式 Logo。

## 兼容性说明

| AI 能力 | 使用方法 | 能保证的部分 |
| --- | --- | --- |
| 支持 Skill/Agent 文件夹、图片和代码 | 导入完整文件夹 | 规则读取、资产调用、精确尺寸与 Logo 合成 |
| 支持系统提示词和文件上传 | 粘贴通用提示词并上传资产 | 规则可迁移；运行脚本后可保证尺寸与 Logo |
| 只支持文字对话 | 粘贴通用提示词 | 只能生成设计方案或提示词，不能直接保证最终图片 |

本包采用通用 Markdown、PNG 和 Python 文件，任何能读取这些格式的 AI 都可以使用其规则和资产。但不同 AI 的生图、中文排版、附件访问和代码执行能力不同，因此无法诚实保证所有平台的生成质量完全一致。**精确 Logo、尺寸和版本选择，只有在运行合成脚本或按相同参数手工合成后才能保证。**

字体文件未随包分发。若需要像素级一致的抖音美好体、阿里妈妈数黑或阿里巴巴普惠体，请在获得合法授权后，在目标平台或排版环境中安装相应字体。
